ВСЕГДА ПОД РУКОЙ

План поставок на iPhone

  1. Откройте эту страницу в Safari.
  2. Нажмите «Поделиться» — значок квадрата со стрелкой вверх. В новых версиях Safari он может находиться в меню «Ещё».
  3. Выберите «На экран Домой». Если есть переключатель «Открывать как веб-приложение», включите его.
  4. Нажмите «Добавить».

После установки откройте приложение с иконки и нажмите «Обновить». Safari и приложение могут хранить отчёты отдельно. Для обновления нужен интернет; сохранённый отчёт доступен без сети, пока iOS хранит данные сайта.
