# Ручное обновление Leo: 0.8.1 → 0.8.2

Подготовлено 15.11.2026. Эта инструкция и архив предназначены для работающего сервера версии 0.8.1. На момент подготовки публичный /health возвращает 0.8.1. Обновление вручную пока НЕ выполнено.

## Что уже сделано

На подключённом Samsung установлена 0.8.2 (versionCode 38) без удаления данных. APK заменён в C:\Users\Vlady\Yandex.Disk\Distrib\ozon-plan.apk. Исходники функции индивидуальной прибыли опубликованы в GitHub main, коммит 6744e56. Android: сборка, unit-тесты и lint успешны; веб: 13 тестов; проверки API/версии: 46 тестов.

## 1. Найдите пакет

На основном компьютере откройте Проводник и вставьте в адресную строку:
C:\Users\Vlady\Yandex.Disk\Distrib

Файл обновления: ozon-server-update-0.8.2.zip.
Перенесите архив на Leo любым доступным вам способом: через Яндекс Диск, USB-накопитель или работающую ручную передачу файлов. Архив должен оказаться на диске Leo. Сами действия по замене выполняются на Leo.

## 2. Проверьте исходную версию

В браузере откройте https://s63j9zcrvhd2.share.zrok.io/health.
До обновления ожидается status=ok и version=0.8.1. Если версия другая, этот сокращённый пакет не заменяет полное обновление серверных Python-модулей: сначала уточните исходную версию. Для текущей 0.8.1 дополнительных Python-модулей и установки зависимостей не требуется.

## 3. Распакуйте архив в отдельное место

На Leo нажмите архив правой кнопкой → «Извлечь всё». Выберите отдельную папку, например Downloads\ozon-update-0.8.2. Не распаковывайте сразу поверх рабочей программы.
Внутри должны быть три элемента: ozon_forecast, updates, version.properties.
Всего пакет содержит 6 файлов:
- ozon_forecast\web\app.mjs
- ozon_forecast\web\model.mjs
- ozon_forecast\web\index.html
- ozon_forecast\web\sw.js
- updates\ozon-plan.apk
- version.properties

В version.properties должны быть строки versionName=0.8.2 и versionCode=38.

## 4. Найдите рабочую папку на Leo

В адресную строку Проводника на Leo вставьте:
C:\Users\vlady\AppData\Local\OzonSalesBot

AppData скрыта, но полный путь в адресной строке открывается без изменения показа скрытых файлов. Ожидаются папки ozon_forecast, data, deployment, updates и другие служебные файлы.
Путь относится к пользователю vlady НА LEO, а не к основному компьютеру.

## 5. Сделайте резервную копию

Рядом с OzonSalesBot, в C:\Users\vlady\AppData\Local, создайте папку OzonSalesBot-backup-before-0.8.2. Если такая уже есть, добавьте к имени время, не перезаписывайте старую копию.
Скопируйте туда из рабочего OzonSalesBot:
- папку ozon_forecast\web (всю папку web);
- папку updates;
- файл version.properties.
Дождитесь завершения копирования. Это копирование, не перемещение.

Не удаляйте и не заменяйте data, .venv, .env, .env.forecast, *.sqlite3. Они содержат рабочие данные, ключи и себестоимость. В архиве их нет.

## 6. Остановите только API

На Leo нажмите правой кнопкой на «Пуск» → «Управление компьютером». Слева откройте «Служебные программы» → «Планировщик заданий» → «Библиотека планировщика заданий».
В центре выберите Ozon Forecast API. Проверьте, что в нижней части указано именно это имя.
Справа нажмите «Завершить», подтвердите «Да». Через несколько секунд состояние должно стать «Готово». При необходимости обновите список.
Не останавливайте Ozon Forecast Tunnel и Ozon Sales Telegram Bot.
Во время остановки API временная недоступность сайта ожидаема.

## 7. Замените ровно шесть файлов

Из распакованного пакета откройте ozon_forecast\web. Выделите app.mjs, model.mjs, index.html, sw.js и скопируйте в:
C:\Users\vlady\AppData\Local\OzonSalesBot\ozon_forecast\web
Подтвердите замену существующих файлов.

Затем скопируйте updates\ozon-plan.apk в:
C:\Users\vlady\AppData\Local\OzonSalesBot\updates

Затем скопируйте version.properties в корень:
C:\Users\vlady\AppData\Local\OzonSalesBot

Не удаляйте папку web перед копированием. В ней должны остаться app.css, storage.mjs, manifest.webmanifest и папка icons. Пакет является дополнением к 0.8.1, а не всей программой.

## 8. Проверьте пути и версию

Правильный путь к интерфейсу:
C:\Users\vlady\AppData\Local\OzonSalesBot\ozon_forecast\web\index.html

Неправильно: OzonSalesBot\Publish082\ozon_forecast\web или OzonSalesBot\ozon_forecast\ozon_forecast\web.
Если включить в Проводнике «Вид → Показать → Расширения имён файлов», можно проверить, что version.properties не превратился в version.properties.txt.
Откройте рабочий version.properties Блокнотом: versionName=0.8.2, versionCode=38. Ничего редактировать не требуется.

## 9. Запустите API

В планировщике снова выберите Ozon Forecast API → справа «Выполнить». Подождите 15–30 секунд. Состояние должно стать «Работает».
Не запускайте дополнительно Python или сервер вручную: иначе можно получить конфликт занятого порта.

## 10. Проверьте сервер и APK

Откройте https://s63j9zcrvhd2.share.zrok.io/health.
Ожидается status=ok, version=0.8.2.

Откройте https://s63j9zcrvhd2.share.zrok.io/api/v1/update.
Ожидается version_name=0.8.2, version_code=38, size_bytes=8108856.
SHA-256 APK: f7e8ad49b5fa3a0470986ad0b936adc10d743dd349887868747aa11444a4734a.
Метаданные показывают версию запущенного API и хеш фактически лежащего APK. Поэтому должны быть заменены и version.properties, и сам APK.

Если сразу после запуска видна 502, подождите ещё 30 секунд и повторите. Если остаётся старая версия, проверьте путь к version.properties и повторите завершение/запуск только API.

## 11. Обновите интерфейс iPhone

Откройте https://s63j9zcrvhd2.share.zrok.io/web/ в Safari или приложение с домашнего экрана.
При сообщении «Доступна новая версия интерфейса» нажмите «Установить» и дождитесь перезагрузки.
Если сообщения нет, обновите страницу Safari, подождите несколько секунд. Закройте веб-приложение через переключатель приложений и откройте снова. Safari и приложение с домашнего экрана могут хранить данные отдельно, поэтому проверьте тот вариант, которым пользуетесь.
Не очищайте данные сайта без необходимости: очистка удалит сохранённые на iPhone отчёты и настройки, в том числе индивидуальную прибыль.

## 12. Проверьте индивидуальную прибыль

Откройте «Рентабельность». Укажите общую желаемую прибыль 200 руб. Если нужно, загрузите отчёт кнопкой обновления.
В карточке одного товара нажмите «Желаемая прибыль / шт. · Изменить». Введите 350 и нажмите сохранение.
Этот товар должен показывать 350 руб. и пометку «индивидуальная»; остальные используют общие 200 руб.
Измените общее значение на 250: индивидуальный товар остаётся на 350, остальные переходят на 250.
В редакторе товара нажмите «Использовать общее значение»: товар перейдёт на 250 и пометку «общая».
Проверьте сохранение: задайте индивидуальное значение, закройте и снова откройте приложение. Значение должно остаться.
Ноль допустим и не означает сброс. Для сброса предназначена отдельная кнопка. «Отмена» не меняет значение.
Изменение прибыли пересчитывает минимальную цену локально, не загружает данные Ozon и не меняет цены магазина. Настройки хранятся на каждом устройстве отдельно.

## 13. Если минимальная цена не появилась

Сообщение «Недостаточно данных» ожидаемо, если себестоимость нулевая/не задана, нет успешных продаж или полной детализации услуг. Оно не доказывает ошибку обновления.
Проверяйте на товаре с ненулевой себестоимостью и успешными продажами. Сохранённый старый отчёт без входных данных тарифа нужно обновить один раз. Для проверки индивидуальных значений сама рассчитанная цена не обязательна: строка желаемой прибыли должна сохраняться независимо от наличия тарифа.

## 14. Если API не запускается

Проверьте шесть путей, наличие прежних app.css/storage.mjs/icons и что вы не заменили рабочую папку сокращённым пакетом целиком. Проверьте, что запускается именно задача Ozon Forecast API.
Логи находятся в C:\Users\vlady\AppData\Local\OzonSalesBot\logs. Откройте свежий лог API (например forecast-api.log, если он есть) и посмотрите последние строки после запуска. Ключи и .env не публикуйте.
В этом обновлении Python-код не меняется. Если ошибка относится к отсутствующему Python-модулю, вероятно, исходная установка была неполной либо файлы случайно удалены.

## 15. Откат

Завершите Ozon Forecast API. Скопируйте из резервной копии обратно web в ozon_forecast, updates и version.properties, подтвердив замену. Запустите только API и проверьте /health. На iPhone повторно обновите страницу; если предложено обновление оболочки, примените.
Рабочие базы и себестоимость для отката трогать не требуется. Если после неудачной попытки требуется удалить лишнюю вложенную папку, сначала убедитесь в правильном пути и сохранности резервной копии.

## Что сообщить после ручной установки

Достаточно двух результатов: /health показывает 0.8.2, а в карточке товара сохраняется индивидуальная прибыль. После этого можно дополнительно проверить опубликованные файлы и APK извне.
