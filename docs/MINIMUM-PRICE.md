# Минимальная цена продавца

Версия 0.8.1. Расчёт доступен в карточках рентабельности отдельно для FBO/FBS. Прибыль на штуку по умолчанию 200 ₽, настройка хранится на устройстве. Изменение прибыли или себестоимости пересчитывает результат без запроса к Ozon. Отправки цен в Ozon нет.

Цена округляется вверх до целого рубля: (себестоимость + средние фиксированные услуги + распределённый кросс-докинг + прибыль) / (1 − текущая комиссия − оценка эквайринга). Средние представлены отношением целых копеек и количества, без промежуточного округления; Android использует BigDecimal, веб — BigInt.

Себестоимость — последнее общее значение производства и налогов. Налог второй раз не добавляется, упаковка не учитывается. Ноль/отсутствие себестоимости, отсутствие успешных продаж, неизвестный характер услуги или неполная детализация дают «Недостаточно данных». KD001, HR001, SK001 исключены.

Выборка: доставленные заказы выбранного периода; начисления по ним до дня обновления. Для тарифа берутся только положительные продажи с комиссией и логистикой. SKU отправления с возвратом исключается целиком (включая частичный возврат — консервативно). Дубли продаж/корректировки не увеличивают число единиц. Отказы/отмены/незавершённые заказы не используются. Для каждой схемы считаются отдельные количество и услуги.

Полная логистика берётся из /v1/finance/accrual/postings, дневная доставка повторно не прибавляется. Комиссия из исторических начислений заменяется актуальной sales_percent_fbo/fbs из /v5/product/info/prices. Эквайринг оценивается как текущее acquiring / marketing_seller_price; исторический эквайринг не добавляется второй раз. Это оценка, тариф может измениться. Звёздные товары и Управление отзывами исключены; неизвестные ненулевые услуги блокируют цену, поскольку неизвестно, являются ли они фиксированными или процентными.

Кросс-докинг NON_ITEM за выбранный период распределяется поровну на успешную единицу FBO среди включённых товаров. FBS его не получает. Это явно показанное допущение, а не фактическая привязка к SKU. Другие общие расходы в будущую цену не распределяются. На исследовательской выборке: 136,80 ₽ / 41 шт. FBO; 3 шт. FBS отдельно. Цена относится к цене продавца с учётом его акций, до скидок Ozon; средняя логистика не гарантирует одинаковую прибыль на каждом маршруте.

Сохранённые отчёты сохраняют входные данные тарифа; при проблемах с сервером их можно пересчитать локально с предупреждением о свежести. Старый отчёт без тарифа показывает недостаток данных до успешного обновления. Ошибка загрузки тарифов не уничтожает основной финансовый отчёт.
